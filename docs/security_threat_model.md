# Security Model & Hardening Controls

This document details the security boundaries, implemented defenses, and intentional scope limits of the P2P file discovery and transfer system.

## 1. Threat Model & Target Environment

- **Primary Environment:** Trusted Local Area Networks (LANs) and localhost development sandboxes (university labs, home Wi-Fi, internal engineering subnets).
- **Honest Limitations:** The `P2P v1` wire protocol does **not** currently negotiate TLS transport encryption or cryptographic peer-identity certificates (`ED25519` / mutual TLS). Confidentiality and peer authentication against active on-path attackers across untrusted public networks are out of scope for the initial LAN implementation.

## 2. Implemented Security Controls

| Threat Vector | Mitigation Implemented | Module(s) |
| --- | --- | --- |
| **Directory / Path Traversal (`../`, `\\`, NUL, control chars)** | Remote peers never supply filesystem paths — they query and request opaque 24-hex `file_id` hashes. Inbound/outbound filenames are validated strictly via [`validate_file_name`](file:///Users/madhurdandev/p2p/src/p2p/network/protocol.py#L104-L118) and [`resolve_shared_file`](file:///Users/madhurdandev/p2p/src/p2p/security/path_validation.py#L45-L70). | [protocol.py](file:///Users/madhurdandev/p2p/src/p2p/network/protocol.py), [path_validation.py](file:///Users/madhurdandev/p2p/src/p2p/security/path_validation.py) |
| **Symlink Escape & TOCTOU Swap** | Recursive directory scanner skips symlinks (`follow_symlinks=false`). Every path segment under the authorized root is checked via `ensure_no_symlink_components`, files are opened using `os.O_NOFOLLOW`, descriptors are checked via `stat.S_ISREG(os.fstat(fd))`, and `.part` files use `open_part_file_safe(..., O_NOFOLLOW)`. PID files and IPC sockets also reject leaf/parent symlinks prior to open/bind. | [path_validation.py](file:///Users/madhurdandev/p2p/src/p2p/security/path_validation.py), [scanner.py](file:///Users/madhurdandev/p2p/src/p2p/indexing/scanner.py), [pidfile.py](file:///Users/madhurdandev/p2p/src/p2p/daemon/pidfile.py) |
| **Memory Exhaustion / Malformed Frame DoS** | Fixed 26-byte binary header validates magic `P2`, version `1`, message code, flags, and `payload_len` **before** calling `readexactly(payload_len)`. Control frames cap at `64 KiB`, chunks at `256 KiB`, UDP datagrams at `1,200 B`. No `pickle` or `eval` exists anywhere. | [framing.py](file:///Users/madhurdandev/p2p/src/p2p/network/framing.py), [serialization.py](file:///Users/madhurdandev/p2p/src/p2p/network/serialization.py) |
| **Slowloris & Socket Saturation** | `TcpServer` bounds concurrent client connections (`max_simultaneous_connections = 64`). `read_frame` enforces `control_timeout_sec = 5.0` and `idle_timeout_sec = 30.0`, closing stalled partial streams automatically. | [tcp_server.py](file:///Users/madhurdandev/p2p/src/p2p/network/tcp_server.py), [upload.py](file:///Users/madhurdandev/p2p/src/p2p/transfer/upload.py) |
| **Request Flooding / Amplification** | `UploadService` protects `SEARCH_REQUEST` and `GET_FILE` with a bounded-memory `SlidingWindowRateLimiter` (`max_requests` per IP window, capped key table), returning structured `RATE_LIMITED` responses instead of allocating work. | [limits.py](file:///Users/madhurdandev/p2p/src/p2p/security/limits.py), [upload.py](file:///Users/madhurdandev/p2p/src/p2p/transfer/upload.py) |
| **Disk Exhaustion & Partial Corruption** | [`check_download_disk_space`](file:///Users/madhurdandev/p2p/src/p2p/security/limits.py#L91-L118) verifies free disk space (`shutil.disk_usage`) and optional directory quotas prior to allocating bytes. Transfers write to isolated `.part` files and must pass full-file SHA-256 verification before `os.replace()`. | [limits.py](file:///Users/madhurdandev/p2p/src/p2p/security/limits.py), [download.py](file:///Users/madhurdandev/p2p/src/p2p/transfer/download.py) |
| **SQL Injection** | Every `sqlite3` query uses `?` parameterized bindings; `LIKE` patterns escape `\`, `%`, and `_` explicitly. | [repositories.py](file:///Users/madhurdandev/p2p/src/p2p/storage/repositories.py) |
| **Local Multi-User Daemon Hijacking** | Daemon Unix domain socket (`p2p.sock`) is restricted immediately via `os.chmod(..., 0o600)` and PID file opens with mode `0o600` under exclusive `fcntl.flock()`. | [ipc_server.py](file:///Users/madhurdandev/p2p/src/p2p/daemon/ipc_server.py), [pidfile.py](file:///Users/madhurdandev/p2p/src/p2p/daemon/pidfile.py) |
